# Contributor instructions

Use English for interface copy, documentation, fixtures and comments. Preserve upstream notices. Keep demo data clearly synthetic and network-free. Never add operational snapshots, tokens or private topology.

Retain unknown/maintenance/stale semantics and gaps in charts. A successful process observation is not application acceptance. Run TypeScript tests/typecheck/lint/build and collector unit tests after behavior changes. Regenerate demo assets when the renderer or fixtures change.
